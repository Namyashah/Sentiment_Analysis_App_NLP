# 📘 NLP Fundamentals

## 1. What is NLP?

**Natural Language Processing (NLP)** is a branch of AI that helps
computers understand, process, and generate human language.

**Why needed?** It helps computers work with text and speech.

**Applications:** Chatbots, sentiment analysis, translation, spam
detection, search engines, and summarization.

## 2. Common NLP Tasks

-   **Tokenization:** Splits text into words or sentences.
-   **POS Tagging:** Identifies nouns, verbs, adjectives, etc.
-   **NER:** Finds names of people, places, and organizations.
-   **Stemming:** Removes word endings.
-   **Lemmatization:** Converts words to their dictionary base form.
-   **Sentiment Analysis:** Identifies positive, negative, or neutral
    opinions.
-   **Text Classification:** Assigns text to categories.

## 3. NLP Approaches

-   **Rule-Based:** Uses predefined rules and dictionaries.
-   **Machine Learning:** Learns patterns from text data.
-   **Deep Learning:** Uses neural networks such as RNNs and
    Transformers.
-   **Hybrid:** Combines different approaches.

## 4. NLP Pipeline

1.  **Collection:** Gather text data.
2.  **Cleaning:** Remove HTML, URLs, and unwanted characters.
3.  **Tokenization:** Split text into smaller units.
4.  **Normalization:** Lowercase, stem, or lemmatize words.
5.  **Feature Extraction:** Convert text into numbers using BoW, TF-IDF,
    or embeddings.
6.  **Modeling:** Train or apply an NLP model.
7.  **Evaluation:** Measure performance using accuracy, precision,
    recall, and F1-score.
8.  **Deployment:** Use the model in an application.

## 5. Challenges in NLP

-   **Negation:** "The product is not good."
-   **Sarcasm:** "Great, another delay!"
-   **Spelling mistakes:** "Gud" instead of "Good".
-   **Ambiguity:** A word can have multiple meanings.
-   **Mixed opinions:** "Good design, but poor battery."
-   **Class imbalance:** One class has many more examples than another.
-   **Context:** Meaning depends on surrounding words or situation.

**Handling challenges:** Preserve negations, clean text carefully, use
context-aware methods, balance datasets, and evaluate each class with
precision, recall, and F1-score.

## ✅ Key Takeaway

NLP enables computers to understand human language. Good NLP systems
need suitable preprocessing, feature extraction, modeling, and
evaluation.
